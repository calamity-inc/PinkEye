How to Use Pinkeye V5 with Battleye Enabled!
--------------------------------------------

Step ONE
========
1. Go to your **Windows Security settings**:
   - Navigate to "Virus and Threat Protection".
   - Click on **Settings for Virus and Threat Protection**.
   - **Disable Realtime Protection**.

2. Return to **Realtime Protection** and scroll down to add a new exclusion:
   - Add an exclusion specifically for the **Temp** folder, which is located at **C:\Users\<username>\AppData\Local\Temp**.

3. Disable/Uninstall VanGuard Anti-Cheat & FaceIt Anti-Cheat to prevent getting the "Failed to load driver." error.

--------------------------------------------

Step TWO
========
1. Return to your **Windows Security settings**:
   - Go to **Device Security**.
   - Click on **Core Isolation Details**.

2. **Disable Memory Integrity**.

3. Restart your device for changes to take effect.

--------------------------------------------

Step THREE
==========
1. Launch **PinkEye V5**.

2. Press **Inject**.

--------------------------------------------

Step FOUR
=========
1. Start your game.

2. Once fully loaded (in **Story Mode**), you should see the **Stand mod menu** injected.

3. You're ready to use **Pinkeye V5** without any issue!

NOTE: When using **PinkEye V5** do NOT close PinkEye after it's done injecting or else the game will close, PinkEye will exit on its own once GTA5 closes. Furthermore if you open PinkEye mid-game, you can double click the PinkEye window to minimize it.

NOTE TO VPN USERS: If you get a auth error when using PinkEye with a VPN, go to https://www.pinkeye.dev/ and do the captcha, after doing the captcha, trying opening PinkEye again.
